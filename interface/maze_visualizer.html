📐 Why is BFS Optimal Here?

In a uniform grid where every step has identical unit cost (c = 1), BFS expands nodes in strictly non-decreasing distance from the start node:

d(Start, v₁) ≤ d(Start, v₂) ≤ ... ≤ d(Start, v_k)

Because a FIFO queue strictly pops all nodes at distance d before any at d + 1, the first time the Goal is dequeued, no remaining unexplored branch can possibly offer a path with fewer edges.

DFS Contrast: Depth-First Search explores paths deeply via LIFO stack, often getting trapped in winding detours (as demonstrated in the "DFS Trap" preset).
